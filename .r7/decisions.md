# Vesper Drift decisions

- **2026-10-02 — Ship a dependency-free browser implementation (renderer superseded 2026-10-03).** `package.json` still has no game dependencies or build step; `src/main.js` remains the 2D path, but `src/boot.js` now defaults to 3D. Evidence: `package.json`, `src/boot.js`, `src/main.js`.
- **2026-10-02 — Separate reference research from implemented design.** `docs/game-design.md` identifies unconfirmed details of the referenced game and labels assumptions. Its earlier 2D implementation description was superseded by the 3D default on 2026-10-03 (`src/boot.js`).
- **2026-10-02 — Make progression and pacing testable.** `src/stages.js` owns stages, choices and endings; `tests/stages.test.mjs`, `tests/pace.mjs`, and `tests/smoke.mjs` cover rules, a deterministic headless run and browser flow. Evidence: `package.json`, `docs/engine-notes.md`.
- **2026-10-03 — Default to 3D with a safe 2D fallback.** `src/boot.js` loads `src/main3d.js` when WebGL2 is available, otherwise loads `src/main.js`; `?renderer=2d` overrides the default. The 3D path uses the seeded simulation in `src/sim/` and vendored Three.js in `vendor/three/` (`src/render3d/`).
- **2026-10-03 — Keep the video project separate from the game runtime.** `video/package.json` has Remotion dependencies and commands; `video/README.md` describes an edit list built from script and source recordings. The top-level game's dependency-free runtime remains separate.
